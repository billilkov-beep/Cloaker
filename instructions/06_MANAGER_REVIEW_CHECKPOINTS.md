# 06 — Manager Review Checkpoints

Pause for approval at each checkpoint.

## A — Repo setup

Provide: repo link, branch protection, Stage 1 import, Cursor summary.

## B — Reuse research

Provide: `docs/REUSE_DECISIONS.md`, dependency/license risks, crypto/library recommendation.

## C — Initial scaffold

Provide: repo structure, run commands, API health endpoint, mobile launch proof, test output.

## D — Private discovery

Demonstrate: discovery off by default, 5-minute timer, exact QR/code only, no name search, approval required, expired token rejected.

## E — Encrypted envelope MVP

Demonstrate: ciphertext only in DB, no plaintext logs, no message text in push, recipient decrypts locally.

## F — Delete-on-disconnect

Demonstrate: either user disconnects, both sides purge, server ciphertext removed/nulled.

## G — Before TestFlight

Provide: build number, release notes, known limitations, crash/log privacy review, no production secrets.
